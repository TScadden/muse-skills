# Genjutsu (curated subset)

Entry points: `skills/cast/SKILL.md` (motion on an existing UI),
`skills/paint/SKILL.md` (visual universe end to end), and
`skills/bunshin/SKILL.md` (whole-site pipeline). Shared modules live in
`skills/_jutsu/`. Upstream: AThevon/genjutsu (MIT). This copy keeps the web
modules and omits the SwiftUI and Jetpack Compose modules and the bundled
GSAP module (superseded by the official GreenSock skills in this library).
